# Тестирование формы заказа карты

[![Build Status](https://github.com/lidasorokina/web-form-testing/workflows/Java%20CI/badge.svg)](https://github.com/lidasorokina/web-form-testing/actions)

## Описание
Автотесты для формы заказа карты с использованием Selenium и JUnit5.

## Запуск
1. Запустите SUT: `java -jar artifacts/app-order.jar`
2. Запустите тесты: `./gradlew test`
